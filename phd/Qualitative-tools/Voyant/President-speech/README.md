# 臺灣總統就職演說互動分析

這是一個不依賴 VoyantServer 的靜態互動網站，包含：

- 1996–2024 年八篇總統就職演說全文與總統府官方來源
- 詞頻趨勢、氣泡線、詞頻圖與 Collocates
- 中國／兩岸與經濟／國家的 Context 逐句編碼
- 三個時期的研究結論

## GitHub Pages

將此資料夾的全部內容放到 GitHub 儲存庫根目錄或 `docs/`，再到 `Settings → Pages` 選擇對應資料夾發布。

網站只使用 HTML、CSS、JavaScript 與 JSON，不需要資料庫或建置程序。

## 資料來源

演說原文來自中華民國總統府；每篇演說的官方網址可在網站閱讀器中開啟。
